# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of my **CodeAlpha Python Internship**.

The program calculates the total investment value based on user-entered stock names, quantities, and predefined stock prices.

## 🎯 Project Objective

The objective of this project is to create a simple program that:

- Accepts stock names from the user
- Accepts the quantity of each stock
- Uses a hardcoded dictionary to store stock prices
- Calculates the investment value
- Displays the total investment
- Saves the result to a `.txt` file

## 🛠️ Technologies Used

- **Python**
- Dictionary
- User Input / Output
- Basic Arithmetic
- File Handling
